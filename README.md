# 羁绊天梯

《云顶之弈》S18 纹章阵容解算器。选择当前拥有的纹章后，浏览器会精确计算 8、9、10、11 人口下可激活的最大非唯一羁绊阵容，并给出纹章分配方案。

## 特性

- 静态数据与图片全部随站点打包，运行时无需联网
- 支持多枚同类纹章和多套同分阵容
- 对每个人口独立求解，标记相对上一人口新增弈子
- 处理拉克丝双计数与满进化卡兹克等特殊规则

## 本地运行

```bash
npm install
npm run dev
```

GitHub Pages 静态构建：

```bash
npm run build:pages
```

数据快照来自 CommunityDragon。本项目与 Riot Games 无隶属或背书关系。
